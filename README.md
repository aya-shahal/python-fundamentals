# 📚 Library Management System (Python OOP)

This project is part of my **python-fundamentals** learning journey. It’s a simple Python program that demonstrates **Object-Oriented Programming (OOP)** concepts using two classes — `Book` and `Library` — to manage books in a small library system.

## 🧠 Features

- Create and manage book objects
- Check out and return books
- Store books in a library collection
- Search for books by title (case-insensitive)
- Display all books with their checked-out status

## 🏗️ Project Structure

book.py # Defines the Book class  
library.py # Defines the Library class  
main.py # Runs the main program

## ▶️ How to Run

1. Clone this repository:  
   git clone https://github.com/your-username/python-fundamentals.git

2. Navigate to the project folder:  
   cd python-fundamentals

3. Run the main script:  
   python main.py
